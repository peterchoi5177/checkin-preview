3분 요약

  • 메뉴가 화면 아래로: 체크인 · 예약 · 청소 · 바베큐 · 더보기
  • 한 예약이 두 줄: 둘째 줄에 채널·도착시간·받을 돈, 요청사항은 빨간 줄
  • 입실은 맨 왼쪽 동그라미, 잘못 누르면 되돌리기
  • 손님 이름을 누르면 상세(전화·메모·현장기록)
  • 근무표·현장기록·지출·현금시제·정산은 더보기
아래 화면은 모두 연습용 가짜 데이터예요.

1첫 화면

위쪽 숫자 칸이 바로 필터예요. '입실 대기'를 누르면 아직 안 온 손님만, '받을 돈'을 누르면 추가요금 받을 손님만 보여요. 입실 대기는 도착이 빠른 순서로 나와요.

2입실 체크 · 되돌리기

  1. 1줄 맨 왼쪽 동그라미를 누르면 입실 완료
  2. 2잘못 눌렀으면 아래 알림의 '되돌리기' (4초)

입실 완료한 손님은 목록 아래 '입실 완료'로 내려가요.

3받을 돈 → 현장기록

  1. 1둘째 줄 오른쪽 주황 금액 = 현장에서 받을 돈
  2. 2위쪽 '받을 돈'을 누르면 받을 손님만 모아 보기
  3. 3손님 줄을 누르면 상세가 올라오고, '현장기록 받기'를 누르면 금액이 미리 채워져요

전화번호와 전화 버튼도 이 상세 화면에 있어요.

4인원 · 요청사항

  1. 1인원은 지금처럼 숫자 칸에 바로 입력. 기본 인원보다 많으면 주황색
  2. 2요청사항이 있으면 빨간 줄로 바로 보여요

5바베큐

  1. 1BBQ 칸을 누르면
  2. 2시간,
  3. 3자리를 고르고
  4. 4저장. 아래 '바베큐' 탭에서 오늘 바베큐를 시간순으로 볼 수 있어요

6메뉴는 어디로?

  1. 1근무표 → 더보기
  2. 2현장기록 목록·지출·현금시제(·정산) → 더보기
  3. 3예약현황·월별 달력 → 아래 '예약' 탭

인수인계·추가이불·검색은 화면 위 오른쪽 아이콘이에요(빨간 숫자 = 할 일).

7PC 화면

  1. 1본사는 지점 이름을 한 번 눌러 바꿔요 (날짜·보기 그대로)
  2. 2숫자 칸 필터는 폰과 같아요
  3. 3받을 돈이 있으면 '받기 +금액' 버튼으로 바로 현장기록
  4. 4이름을 누르면 오른쪽에 상세가 열려요

표는 그대로 한 줄 = 한 예약이고, 같은 뜻의 칸만 묶었어요. 인쇄는 지금 양식 그대로예요.

  2. 2객실을 누르면 청소 필요 → 청소 완료 → 검수 완료
